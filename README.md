# 启禾影视设备分发

这是一个完全使用 GitHub 免费功能的 TVBox 配置分发器。

## 管理方法

打开仓库的 **Actions → 启禾影视设备管理 → Run workflow**：

- `新增或续期`：填写设备编号、名称、有效天数。
- `停用`：填写设备编号，约几分钟内生成停用配置。
- `启用`：恢复设备；如果已经过期，还需执行一次“新增或续期”。

设备地址格式：

`https://raw.githubusercontent.com/aliang8886/qihe-tvbox/main/devices/设备编号.json`

定时任务每天北京时间约 03:17 检查一次到期状态，因此到期控制最多可能延迟不到 24 小时。TVBox 本身如果缓存配置，还需刷新或重启。
